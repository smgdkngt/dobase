Open-source app that replaces your scattered SaaS tools with a single self-hosted workspace. Mail, boards, docs, chat, and more — all under your control.

View on GitHub Self-host

Eight tools, one app.

Install only what you need. Each tool can be shared with different collaborators, or kept private.

Mail

IMAP/SMTP email with threaded conversations, search, drafts that sync, and calendar invites you accept right from the message.

Board

Kanban boards with labels, due dates, assignees, comments with @mentions, attachments, and an archive.

Docs

Rich text documents several people write in at once — you see each other's cursors, live.

Chat

Real-time messaging with replies, @mentions, edits, file sharing, and who's online and typing.

Todos

Task lists with due dates, assignees, repeating tasks, comments, and attachments.

Files

Folders, a picture gallery with slideshow, readable text, markdown and code, and public links with a password and an expiry date.

Calendar

Syncs with any CalDAV server — iCloud, Fastmail, Nextcloud — or runs on its own. Recurring events and invites.

Room

Video calls powered by LiveKit, with screen sharing, right inside your workspace.

Everything you'd expect, and then some.

Search everything

Hit Cmd+K to jump to any tool or action — or keep typing to search cards, todos, documents, files, chat, events and mail at once.

Keyboard first

Every tool ships with a full set of shortcuts and a ? overlay that lists them.

Notifications & @mentions

Mention someone and they hear about it. Activity dots show what's new since your last visit, pushed live — and an email digest for when you're away.

Share per tool

Invite people as owners or collaborators, one tool at a time. Permissions are explicit and never global.

API & command line

Every tool answers JSON with a personal access token, read-only if you like. The dobase CLI — and AI agents — work in your workspace through it.

Two-factor auth

TOTP-based 2FA with any authenticator app, and recovery codes for the day you lose your phone.

Accessible

Works from the keyboard and with a screen reader, meets WCAG AA contrast, and respects reduced motion.

Light and dark

Follows your system's appearance, everywhere, including the emails it sends.

Mobile-friendly

Responsive on any screen. Add it to your home screen as a PWA for a native-app feel.

Work together, live.

Dobase shows you who's there and what they're doing, the moment they're doing it.

Write in the same document

Everyone types at once and the text merges as you go. Each person's cursor shows up in their own colour, with their name — no locking, no "Marcus is editing".

See who's where

Faces beside every tool in the sidebar and at the top of the page show who's in. The card, todo or file someone has open gets a ring — and inside it, you can see them writing a comment before it lands.

Find anything, from anywhere

One search box for every tool you share: cards, todos, the text of your documents, files, chat, events and mail. Enter opens it, right where it lives.

Your data, your rules.

Dobase runs on your server. No analytics, no tracking, no third-party data sharing. One Rails app, one SQLite database, one Docker container. That is the entire stack.

Self-host anywhere.

Install with ONCE for the easiest setup — backups, updates, and SSL handled automatically. Or deploy with Kamal for zero-downtime deploys with LiveKit video. Works on any VPS, cloud server, or Raspberry Pi.

Or try it right now: the command here runs Dobase on http://localhost. On a server with a domain, let ONCE or Kamal take care of HTTPS.

$ docker run -d -p 80:80 \ -v dobase:/rails/storage \ -e DISABLE_SSL=true \ ghcr.io/smgdkngt/dobase
